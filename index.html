Privacy Policy for JobFill BD

Product: JobFill BD (Browser Extension — Chrome & Microsoft Edge MV3)
Version: 2.0.0 (First Public Release — Local-Only Storage Mode)
Publisher: MR Software Studio
Effective Date: November 11, 2026
Last Updated: November 11, 2026
Local-Only First Release Summary (Version 2.0.0 — Cloud Sync Disabled) In JobFill BD v2.0.0 (the first public release for Microsoft Edge Add-ons and Google Chrome), all personal applicant profiles, education/employment records, uploaded photos, signatures, certificates, bookmarks, application tracker entries, and autofill logs are stored strictly on your device inside local encrypted browser storage. Online user accounts and Cloud Sync are completely disabled and inactive in this release (__JOBFILL_CLOUD_SYNC_DISABLED__=true), so no profile data or personal files are uploaded to any developer backend or cloud server. Public job circular discovery requires Internet access and performs read-only HTTP GET requests (credentials: 'omit') with zero personal data.

1. Introduction, Overview & Scope

This Privacy Policy explains how MR Software Studio processes and safeguards user information inside the JobFill BD Manifest V3 browser extension (v2.0.0). JobFill BD helps Bangladeshi job applicants organize application profiles, resize and validate photographs and signatures locally, discover official public job circulars, track application deadlines, and semi-automatically fill recruitment forms under explicit user review.

This policy is published publicly at https://mahfuzar148.github.io/jobfill-bd-privacy/ and bundled identically inside the extension package (privacy.html). This page runs zero JavaScript, sets zero cookies, loads no external fonts or analytics, and contains no forms.

3. Personal Profile Information

If you choose to create local applicant profiles inside the Dashboard, you may save:

  • Identity & Family Details: Applicant name (English/Bengali), father's and mother's names (English/Bengali), spouse's name (if applicable), date of birth, gender, nationality, marital status, and religion (only where requested by public recruitment portals).
  • Government Identifiers & Quota Information: National ID (NID), Birth Registration Number, Passport number and expiry date, quota category, freedom-fighter or disability quota/certificate details, and departmental/employment status.
  • Contact & Postal Addresses: Mobile number, confirm mobile, email address, and present/permanent addresses (care of, village/road/house/flat, division, district, upazila, post office, post code).
  • Recruitment-Specific & Referee Attributes: Height, weight, chest measurements, blood group, exam center, question version, cadre/non-cadre/organization preferences, and referee contact details.

4. Education & Employment Information

  • Secondary & Higher Secondary (SSC / HSC): Examination name, board, institution, roll number, registration number, group/subject, result type, GPA/scale, and passing year.
  • Higher Education & Additional Qualifications: Graduation/Masters degree titles, major/subject, university/college, student ID/roll/registration/session, CGPA, course duration, appeared status, exam dates, and training/diploma/language skills.
  • Employment History: Organization type, employer name, designation, work address, start/end dates, current employment flag, salary, and job responsibilities.

Normalized records stored in education_records and experience_records are persisted as AES-256-GCM ciphertexts inside IndexedDB.

5. Documents, Photos & Signatures

  • Supported File Types: Applicant Photograph, Signature, National ID card scan, Birth Certificate, Educational Certificate, and Other supporting files.
  • Client-Side Image Processing: Photo resizing (such as 300×300 px) and signature sizing (such as 300×80 px) run offline inside your browser using HTML5 Canvas, storing a processed copy while keeping your original file untouched.
  • Local Encryption & Explicit Attachment: Plaintext image Data URLs are stripped before saving to IndexedDB; image bytes are encrypted at rest via AES-256-GCM and attached to a webpage file input only after you explicitly review and click approve.

6. Active Webpage DOM Access & Autofill Behavior

JobFill BD inspects form elements on open web pages solely to help you populate your saved application details accurately:

  • Where Scripts Operate: Bundled content scripts run automatically only on declared Bangladeshi recruitment domains (*.teletalk.com.bd, *.gov.bd, *.bb.org.bd, *.org.bd, *.ac.bd, *.bdjobs.com). On any custom non-declared career website, scripts run only after you explicitly click the JobFill BD popup/action and grant per-site access via activeTab / optional_host_permissions.
  • Strict Safety Exclusions: Google Meet, Zoom, YouTube, Google Workspace/Accounts (Mail, Drive, Docs, Calendar, Login), and internal browser pages (chrome://, edge://, extension stores) are blocked statically in manifest.json (15 exclusion patterns) and dynamically in runtime policy checks. JobFill BD never hooks getUserMedia, getDisplayMedia, RTCPeerConnection, page fetch, or XMLHttpRequest.
  • Human-in-the-Loop Protection: Deterministic local matching runs inside your browser with zero external AI calls. Filling sensitive fields over unencrypted http:// portals triggers a warning overlay requiring explicit confirmation. JobFill BD never clicks Final Submit or Pay Now buttons, and never fills or bypasses CAPTCHA or OTP challenges.

7. Public Job Circular Source Requests

Retrieving public job circulars and official deadlines requires an active Internet connection on manual refresh or scheduled MV3 background alarms:

  • Read-Only GET Requests With Zero PII: Job fetching uses unauthenticated HTTP GET requests with credentials: 'omit'. No applicant profile data, NID, phone number, email, document file, or session cookie is included in public job requests.
  • Approved Configured Sources: Public circular adapters query public endpoints on Teletalk Alljobs (alljobs.teletalk.com.bd), Bangladesh National Portal & ministry/university portals (bangladesh.gov.bd, mopa.gov.bd, dshe.gov.bd, doict.gov.bd, dme.gov.bd, techedu.gov.bd, dghs.gov.bd, cabinet.gov.bd, mof.gov.bd, www.du.ac.bd, www.buet.ac.bd, petrobangla.org.bd), BPSC (bpsc.gov.bd), Bangladesh Bank (erecruitment.bb.org.bd), NTRCA (ntrca.gov.bd), DPE (dpe.gov.bd), Bdjobs static JSON (storage.googleapis.com), Google News RSS feeds (news.google.com), Remotive, Remote OK, Himalayas, Arbeitnow, and optional ReliefWeb API v2 (api.reliefweb.int — active only if you optionally enter your own approved ReliefWeb appname in Preferences, which is sent as a query parameter solely to ReliefWeb).
  • Anti-Bot & CAPTCHA Respect: Automated job fetching stops immediately and enters backoff whenever a portal serves a CAPTCHA or anti-bot challenge.

Version 2.0.0 Status: Cloud Sync Disabled & Inactive Across Store Builds JobFill BD v2.0.0 is released strictly in Local-Only Mode (__JOBFILL_CLOUD_SYNC_DISABLED__=true) for both Microsoft Edge Add-ons and Google Chrome Web Store distributions. 10. Encryption & Security Practices

  • AES-256-GCM Local Encryption: Sensitive applicant data, normalized academic/employment rows, and document files in IndexedDB are encrypted using Web Crypto AES-256-GCM with 12-byte random initialization vectors (IVs).
  • Key Derivation & Vault Lock: By default, a non-extractable device CryptoKey resides inside IndexedDB. When you set an optional Master Vault Password, keys are derived locally via 100,000 iterations of PBKDF2-SHA256 with a random 16-byte salt; your raw password is never written to storage, and unlocked keys exist only in transient memory until locked manually or after your auto-lock timeout (default 15 minutes).
  • Code Hygiene & Masked Logs: Bundled extension pages enforce Content Security Policy (script-src 'self'; object-src 'self';), contain zero eval() or remote script loads, mask sensitive digits in local logs, and strip URL query/hash parameters before writing autofill history.

11. User Consent & Operating Controls

  • Explicit Tab Permission & Review: Custom non-declared websites are accessed only after user interaction and explicit browser permission confirmation.
  • Insecure HTTP Guardrail: Placing sensitive personal identifiers onto legacy non-HTTPS pages requires acknowledging an explicit confirmation warning dialog.
  • No Hidden Cloud Uploads: Because Cloud Sync is disabled in v2.0.0, all data stays strictly local by design.

12. Data Retention & Deletion

  • Local Retention Limits: Profiles, documents, bookmarks, and application tracker records remain on your device until deleted by you or upon uninstalling JobFill BD. Local autofill history caps at 100 sessions; in-memory diagnostics cap at 50 hostname-only records.
  • Instant In-App Deletion: In Security & Backup, Delete Local Private Vault Data (deleteLocalUserData()) deletes profiles, documents, vault keys, bookmarks, applications, notifications, and autofill logs while retaining public job listings; Purge All Profiles & Data (purgeAllData()) wipes every IndexedDB object store and extension storage key cleanly.
  • Extension Removal: Uninstalling the extension removes all extension-owned browser storage.

13. Backup & Restore

  • Offline Local Export: Export your applicant profiles to a local .json file anytime, choosing either a PBKDF2 + AES-256-GCM password-encrypted backup (recommended) or unencrypted JSON.
  • Local Schema-Validated Restore: Restoring a JSON backup runs offline with schema verification and passphrase decryption in browser memory.

14. Notifications & Job Reminders

  • MV3 Alarms & Local Filtering: Scheduled circular checks (jobfill_daily_job_check, default 9:00 AM Asia/Dhaka) and consolidated deadline reminders (jobfill_deadline_scheduler) filter cached circulars against your local preferences and trigger standard desktop notifications via chrome.notifications.

  • Full Local Control: Inspect, edit, switch profiles, toggle Vault Lock, export local backups, or permanently delete all saved data inside the extension Dashboard anytime.
